# flexlayer-render

Capped addon. `engine()` is `flexlayer-render/0.0.2+cap1080`. `index.cjs` loads the `.node` for this machine. `renderStylePng` and `renderScenePng` are on the same binary.

linux-x64-gnu and darwin-arm64 are in this directory. The darwin binary is cross-compiled and has not been run on a Mac. Windows is not included. There is no `draw/` directory.
