# flexlayer-render

Capped addon. `engine()` is `flexlayer-render/0.0.2+cap1080`. `index.cjs` loads the `.node` for this machine. `renderStylePng` and `renderScenePng` are on the same binary.

linux-x64-gnu, darwin-arm64, and win32-x64-msvc are in this directory. All three are built from flexlayer-render commit `05cb34f` and report `flexlayer-render/0.0.2+cap1080`. The darwin and Windows binaries are cross-compiled and have not been loaded on those hosts. There is no `draw/` directory. The unlimited build is not exported.
