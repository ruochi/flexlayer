# flexlayer-render

Capped addon. `engine()` is `flexlayer-render/0.0.2+cap1080`. `index.cjs` loads the `.node` for this machine. `renderStylePng` and `renderScenePng` are on the same binary.

linux-x64-gnu, darwin-arm64, and win32-x64-msvc are in this directory. All three are `flexlayer-render/0.0.2+cap1080`. The darwin binary is cross-compiled and has not been run on a Mac. The Windows binary is cross-compiled and has not been loaded on Windows. There is no `draw/` directory.
